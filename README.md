# educ

مشروع تطبيقي من منصة سطر للتحقق من اجتياز دورة أساسيات Git.

## محتوى المشروع

```
educ/
├── HTML/
│   └── index.html
├── CSS/
│   └── style.css
├── JavaScript/
│   └── example.js
└── README.md
```

## وش تعلمت

- إنشاء repo محلي باستخدام `git init`
- تتبّع الملفات وحفظها بـ `git add` و `git commit`
- متابعة حالة المشروع بـ `git status` و `git log`
- إنشاء الفروع والتنقل بينها
- ربط الـ repo المحلي بـ GitHub ورفع التعديلات بـ `git push`

## أوامر استخدمتها

| الأمر | الوظيفة |
|---|---|
| `git init` | إنشاء repo جديد |
| `git add .` | تجهيز كل الملفات للحفظ |
| `git commit -m "..."` | حفظ لقطة مع رسالة |
| `git push` | رفع التعديلات لـ GitHub |
